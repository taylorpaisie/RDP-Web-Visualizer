What this version supports

This first browser-only version is grounded on the RDP5 CSV Code 1 example supplied for an event plot. It reads the gene map, event metadata, breakpoint confidence intervals, plot colors/roles, and numerical plot data. Additional RDP CSV codes can be added from real examples as they become available.

Nothing is uploaded to a server by this application. Folder access requires an explicit browser permission grant and works best in current Chrome or Edge on HTTPS.
