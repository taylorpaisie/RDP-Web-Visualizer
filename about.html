About the project

RDP output, easier to explore.

RDP Web Visualizer turns RDP5 CSV exports into interactive figures for teaching and exploratory visualization.

The viewer supports RDP CSV Codes 1 through 12, based on supplied RDP v5.93 exports. Plot values and event annotations appear alongside a six-track reading-frame map with directional ORF arrows.

Supported plots

  • Codes 1–3: pairwise comparison curves, GENECONV boxes, and SiScan substitution-series Z-scores.
  • Codes 4–6: single- and multi-sequence 3SEQ curves with permutation envelopes, and MaxChi comparison curves.
  • Codes 7–8: multi-sequence and single-recombinant CHIMAERA curves with informative-site positions.
  • Codes 9–10: PhylPro correlation coefficients and pairwise distances. Distance plots put zero at the top and increase downward.
  • Code 12: breakpoint density with nested 95%/99% envelopes and faint breakpoint ticks between the plot and ORF map.
  • Code 11: recombination event maps with one outlined box per event, using its exported alignment coordinates, height, and hexadecimal color.

Explore events and their details

Hover over curves to inspect values, or near a Code 11 box boundary to see the event number, detection method, recombinant, parents, coordinates, p-value statistic, distance, and color. Use the legend to hide an item, isolate it with Only, or restore everything with Show all.

Breakpoint calls, 95% and 99% confidence intervals, and significance cutoffs are shown when provided by the CSV. Use Zoom to event to focus on reported breakpoints and Full alignment to reset the view. The Code 11 overview has no single event breakpoint to zoom to.

Download the current view as PNG, SVG, JPEG, or WebP, including the selected comparisons or events and an annotation key. Code 1 curves use a normalized display with raw values in hover details; PhylPro coefficients, distance values, and event-box heights retain their exported values. The CSV determines these values even when a reference screenshot shows a different scale.

Your files stay in your browser

Choose an RDP output folder in Chrome or Edge to follow the newest CSV automatically, or choose a single CSV in other browsers. Selected files are processed locally in your browser without uploading their contents to a server.

Built around RDP

This project visualizes exported results. It does not run recombination detection or independently validate an event. When reporting analyses, cite RDP5 and the relevant detection methods.
