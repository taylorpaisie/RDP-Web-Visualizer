What this version supports

This browser-only version is grounded on real RDP5 CSV Code 1 and CSV Code 2 examples. Code 1 renders pairwise-comparison curves; Code 2 reproduces the GENECONV-style transparent rectangle outlines using start, end, and height values, together with the upper cutoff and recombinant interval. Both formats include the ORF map, event metadata, breakpoint information, and RDP-matched comparison colors.

Nothing is uploaded to a server by this application. Folder access requires an explicit browser permission grant and works best in current Chrome or Edge on HTTPS.
