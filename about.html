About the project

⛧ Hail thyself. Question everything.

RDP output, easier to explore.

RDP Web Visualizer turns RDP5 CSV exports into interactive figures for teaching and exploratory visualization.

Explore comparison curves, breakpoint calls, confidence intervals, and open reading frames together. The viewer supports CSV Code 1 and Code 2 exports, with zoom, hover details, and figure downloads.

Your files stay in your browser

Choose an RDP output folder or a single CSV. Selected files are processed locally in your browser without uploading their contents to a server.

Built around RDP

This project visualizes exported results. It does not run recombination detection or independently validate an event. When reporting analyses, cite RDP5 and the relevant detection methods.
